# 扩展中心

TraceMemo 内置「扩展」工作区，让你无需修改主程序即可安装官方模板或第三方扩展，扩展群聊交互、自定义自动化动作或独立交互页面。

---

## 1. 安装扩展的三种方式

在左侧导航进入 **扩展** 后，可以通过以下方式安装：

1. **官方模板画廊**：点击顶部的 **官方模板**，浏览内置模板（例如关键词自动回复、群聊机器人、抖音解析发送等），一键安装到本地。
2. **安装本地目录**：点击 **安装目录**，选择一个包含 `manifest.json` 的扩展目录；开发模式下还支持基于模板创建项目并一键重新加载，或将开发目录「转为正式安装」。
3. **安装 ZIP 包**：点击 **安装 ZIP**，导入打包好的扩展压缩包。安装时会自动校验路径与符号链接，拒绝越界文件。

> 新安装的扩展默认处于 **已停用** 状态，不会在未经你确认的情况下自动运行或发送任何微信消息。

---

## 2. 权限分级与手动授权

每个扩展必须在 `manifest.json` 中声明所需权限，界面会按风险从高到低展示：

| 风险等级 | 权限标识 | 说明 |
| --- | --- | --- |
| 高风险 | `messages.subscribe`、`messages.query` | 接收实时新消息事件，或按会话与时间窗口读取受限历史消息 |
| 高风险 | `wechat.send.text` / `image` / `video` / `voice` | 经 TraceMemo 官方 Gateway 发送文本、图片、视频或语音 |
| 中风险 | `contacts.list`、`ai.chat`、`automation.action`、`secrets` | 读取群列表、调用已配置 AI Provider（不暴露 API Key 明文）、注册自动化动作、使用系统安全存储保存私有凭据 |
| 低风险 | `storage` | 仅读写该扩展独立的数据目录 |

- **高风险权限需要二次确认**：授权高风险权限时界面会弹出确认提示；低风险权限可直接授权。
- **权限变更需重新授权**：扩展升级或新增权限声明后，需你确认授权后后台才会重启生效。
- **沙箱隔离**：每个扩展后台运行在独立的受限子进程中，扩展 UI 运行在受限的沙箱 `iframe` 内，无法直接访问你的微信数据库文件或系统完整权限。

---

## 3. 启用、预览与卸载

- **启用 / 停用**：在左侧已安装列表中选中扩展，点击详情区右上角的 **启用** 或 **停用**。
- **发送能力前置条件**：如果扩展声明了微信发送权限，但当前未绑定个人微信或本机发送组件未就绪，你仍可打开其页面进行预览配置，但无法启用后台发送。
- **与自动化协同**：声明 `automation.action` 的扩展会在「自动化」规则编辑器中注册可选动作，仅在你主动配置的规则触发时执行。
- **卸载与数据保留**：卸载扩展时默认保留该扩展的私有数据目录（也可选择一并清除），避免误删配置。
